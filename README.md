# Viral Shorts 8-bit UI

A retro-styled dashboard for turning long-form YouTube videos into viral Shorts moments.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Database:** Prisma (SQLite)
- **UI:** Shadcn/UI with 8-bit retro theme
- **Validation:** Zod
- **Font:** Press Start 2P

## Getting Started

1. Copy `.env.example` to `.env`
2. Install dependencies: `npm install`
3. Push the database schema: `npx prisma db push`
4. Start the development server: `npm run dev`

## Features

- Analyze YouTube videos for potentially viral moments.
- Retro pixel art aesthetic.
- Form validation with Zod.
- Data persistence with Prisma.
